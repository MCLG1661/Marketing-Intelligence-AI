# Security policy

## Scope

This policy covers the contents of this repository. It does not imply production certification, a support SLA, or responsibility for third-party services.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature if enabled. Otherwise, contact the repository owner privately through the contact information on [the GitHub profile](https://github.com/MCLG1661).

Do not publish credentials, personal data, exploit details or other sensitive information in public issues. Include the affected version or commit, a description of the issue and safe reproduction steps.

## Handling sensitive information

Never commit API keys, access tokens, passwords or private datasets. Use local environment variables or the secret management facilities of the relevant platform. Third-party service vulnerabilities should be reported to their respective maintainers.

Reports are reviewed on a best-effort basis.
