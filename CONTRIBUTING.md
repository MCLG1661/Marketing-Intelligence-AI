# Contributing

This repository is maintained as a professional portfolio project. Before proposing substantial changes, discuss the scope with the maintainer.

For proposed contributions, use a separate branch and a focused pull request. Describe the purpose, affected files, validation performed and any limitations. Preserve existing attribution and third-party terms. Do not include credentials, confidential data or personal information.

Run applicable existing checks before submitting changes. Documentation-only projects do not require executable tests. Security concerns should follow [SECURITY.md](SECURITY.md).

A contribution proposal does not imply acceptance or a commitment to ongoing support.
